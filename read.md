Gmail to Google Sheets Automation
Overview

This project reads unread emails from Gmail using the Gmail API and stores relevant email details into a Google Sheet using Python. It uses Google OAuth 2.0 for secure authentication and avoids duplicate entries.

2.Setup Instructions

Clone the GitHub repository to your local system.
Install the required Python libraries using pip.
Create a project in Google Cloud Console.
Enable Gmail API and Google Sheets API.
Configure the OAuth consent screen.
Download the credentials.json file.
Place credentials.json in the project root directory.
Run the main.py file.
Complete Google OAuth authentication.
Unread Gmail messages will be fetched and stored in Google Sheets.

3.OAuth Flow Used

This project uses Google OAuth 2.0 for authentication.
When the script runs for the first time, the user is redirected to the Google OAuth consent screen. After granting permission, Google generates an access token. This token is stored locally and reused in future executions, so the user does not need to authenticate again.

4.Duplicate Prevention Logic

Each Gmail email has a unique Message ID.
Before inserting data into Google Sheets, the script checks whether the Message ID already exists in the sheet.
If the ID is found, the email is skipped to prevent duplicate records.

5.State Persistence Method

After successful OAuth authentication, the access token is saved locally.
This allows the application to remember the authenticated session and avoid repeated login requests on subsequent runs.

6.Challenges Faced

Challenge:
OAuth authentication failed initially due to incorrect Gmail API scopes.

Solution:
The correct Gmail API scopes were added, and the existing token file was deleted and regenerated by re-authenticating.

7.Limitations

Only unread emails are processed.
Supports only one Gmail account.
Processing large inboxes may take more time.
